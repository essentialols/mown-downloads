-v2018-09-12:Current official release
Inclusion of Haiti 2016 and India 2012
General revision, mostly of missing labels.
-v2016-01-01:Official release
Errata in Argentina fixed: Child qualties (V13-V22) is reversed.
Inclusion of India 2012 (two regions missing from this sample)
- v2015-04-18: Fourth release
Includes new country: Georgia
Adds Welzel's Overall Secular Values and Emancipative indexes and component sub-indexes
- v2014-11-07: Third release
Includes new countries: Argentina, Brazil, Bahrain, Hong Kong, India, South Africa and Thailand
- v2014-04-29: Second release
Fixes errors for the following variables:
  • V144: Religious denomination
  • V58: How many children do you have

  • Y001 post-materislist index 12-item
